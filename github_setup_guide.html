GitHub Actions 设置指南

视频号发布自动检测系统 | 完全免费 | 每天自动运行
1

注册 GitHub 账号

打开 https://github.com/signup 注册账号（免费）：

  - 邮箱：用你的 QQ 邮箱 3117528621@qq.com 即可
  - 用户名：随便取，英文即可（记住它，后面要用）
  - 密码：自己设一个

注意：注册后 GitHub 会发验证邮件到你的邮箱，记得去点确认链接。
注册完成后，把你的 GitHub 用户名 告诉我，我帮你把代码推上去。
2

创建新仓库

登录 GitHub 后，点击右上角 + 号 → New repository：

  - Repository name: video-channel-monitor（或你喜欢的名字）
  - Description: 视频号发布自动检测系统
  - 选 Public（公开仓库 GitHub Actions 免费无限用）
  - 不要勾选 "Add a README file" 等选项
  - 点击 Create repository

为什么选 Public？公开仓库 GitHub Actions 不限时、GitHub Pages 免费。仓库里只有视频号发布状态数据，不含敏感信息。API Key 通过 Secrets 安全注入，不会泄露。
3

推送代码到仓库

创建完仓库后，GitHub 会显示一个页面。把仓库地址（类似下面这个格式）告诉我：

https://github.com/你的用户名/video-channel-monitor.git
我会帮你执行 git 推送命令，把所有代码和历史数据上传到 GitHub。
4

配置 API Key（Secrets）

代码推送完成后，在 GitHub 仓库页面：

  1. 点击 Settings（仓库设置）
  2. 左侧菜单找到 Secrets and variables → Actions
  3. 点击 New repository secret
  4. 填写：
    - Name: TIKHUB_API_KEY
    - Secret: （我会把你的 API Key 发给你，复制粘贴进去）
  5. 点击 Add secret

安全说明：Secrets 加密存储，只有 Actions 运行时才能读取，任何人都看不到明文。
5

开启 GitHub Pages（在线看板）

在同一个 Settings 页面：

  1. 左侧菜单找到 Pages
  2. Source 选择 Deploy from a branch
  3. Branch 选择 main / root
  4. 点击 Save

等待 1-2 分钟后，你的看板就会上线：
https://你的用户名.github.io/video-channel-monitor/

之后每天 21:00 自动检测后，看板数据会自动更新。

6

手动测试一次（可选）

所有配置完成后，可以手动触发一次测试：

  1. 在仓库页面点击 Actions 标签
  2. 左侧选择 视频号每日检测
  3. 点击右侧 Run workflow → Run workflow
  4. 等待几分钟，点进去看运行日志，确认检测成功

如果看到绿色对勾 ✓，说明一切正常！之后每天 21:00 自动运行。
